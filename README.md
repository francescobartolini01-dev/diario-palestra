# Diario di palestra

Web app installabile (PWA) per registrare allenamenti, carichi, peso corporeo e vedere report settimanali o mensili con consigli di recupero.

- I dati sono salvati sul dispositivo (localStorage). Usa "Scarica backup" ogni tanto.
- Funziona anche offline dopo la prima apertura.
- Consigli AI facoltativi: imposta `ANTHROPIC_API_KEY` nelle variabili d'ambiente del progetto Vercel e rifai il deploy.
